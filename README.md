# Owndock – Testversionen

Hier liegen Testversionen von **Owndock** für Android, solange die App noch
nicht im Google Play Store ist.

Owndock ist eine App, in der jede Webseite ihre eigene App-Ansicht bekommen
kann: Adresse eingeben, fertig.

## Installieren

1. Unter [Releases](../../releases/latest) die neueste `.apk`-Datei auf dem
   Android-Handy herunterladen.
2. Die Datei antippen. Beim ersten Mal fragt Android, ob Apps aus dieser
   Quelle installiert werden dürfen – erlauben.
3. Fertig. Neue Testversionen meldet Owndock beim Start selbst
   („Update verfügbar“).

> Testversionen können Fehler enthalten. Der Quellcode von Owndock ist
> nicht öffentlich.
